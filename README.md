# homebrew-tap

Personal Homebrew tap for MarlinL projects.

## Formulae

- `vcd`: open Git projects inside local Docker containers for vibe coding workflows.

## Usage

```sh
brew tap marlinl/tap
brew install vcd
```

You can also install directly with:

```sh
brew install marlinl/tap/vcd
```
